**Self-hosted** web app to track a personal investment portfolio. Everything is stored in SQLite and runs on your own machine or a home server with Docker.

Market quotes are optional: without API keys you enter prices yourself. The interface is in Spanish.

## ✨ Features ✨

- **Portfolio**: summary, per-asset page with average price and performance split into asset effect and currency effect, and investment plans.
- **Finances**: expenses, income, recurring income with extra payments, monthly payments, cash accounts, dividends, fixed income and bonds.
- **Spanish taxation**: sales with FIFO, the two-month rule and loss offsetting; annual report in CSV and HTML.
- **Metrics**: TWR, XIRR, drawdown, volatility and comparison against indices.
- **Crypto**: stablecoins, trades, conversions, staking and earn. Read-only wallet linking (Bitcoin by address —Legacy, SegWit or Taproot—, xpub/ypub/zpub —including Taproot accounts— or single public key, with automatic format detection; Ethereum and BNB Smart Chain by address or public key; Solana and XRP) that imports on-chain movements into Transactions, plus a **Seguimiento** page with the balance, euro value and latest movements of your own wallets and of third-party ones you follow, with optional Telegram alerts on every new movement; addresses and xpubs are stored encrypted and never shown in full.
- **Alerts**: per-asset price alerts and sharp-drop and sharp-rise, position return, price vs. average cost, missing quote, portfolio value, portfolio drop and asset weight alerts (on one asset or the whole portfolio) sent by Telegram, watched by the server even with the web app closed.
- **Operations**: automatic backups, Telegram alerts and commands, optional two-step login with a code sent by Telegram, HTTPS enabled from the app itself, and an iOS Shortcut to log expenses from your phone.
- **Self-updating**: `docker-update.sh` checks that the new version answers on `/api/health` and rolls back to the previous image if it does not.

## 📦 Installation guide ⚙️

### Option 1: Docker (recommended)

```bash
git clone https://github.com/FranciscoFdez05/PorfolioManager.git
cd PorfolioManager
./docker-setup   # creates .env, generates SECRET_KEY, asks for credentials and port, starts the stack
```

The stack runs the web app, a **worker** service with the same image for background tasks (automatic backups, snapshots, Telegram and alerts for prices, wallets and Satoshi's coins, so they never take gunicorn's threads), the Caddy proxy and the update watcher. Run it as your normal user, without `sudo`. The app is served at `http://localhost:5050` (or `http://<SERVER_IP>:5050` from another device on the LAN). Data is kept in `data/`, `logs/` and `API/`.

> [!WARNING]
> Out of the box the app is served over plain HTTP, so the password and session cookie travel unencrypted. Before using it from another device, enable HTTPS in **Ajustes › Seguridad › HTTPS**. See [SECURITY.md](SECURITY.md).

To update an existing installation:

```bash
./docker-update.sh              # git pull, build, start and health check, with automatic rollback
./docker-update.sh --sin-pull   # same, without git pull
```

### Option 2: from source

```bash
git clone https://github.com/FranciscoFdez05/PorfolioManager.git
cd PorfolioManager
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python python/server.py   # http://localhost:5050
```

### Environment variables

Secrets live in `.env` (copy `.env.example`; `./docker-setup` does it for you). The rest of the settings are in `config.ini`.

| Variable | Description | Required | Default |
|---|---|---|---|
| `SECRET_KEY` | Signs sessions and encrypts stored API keys and credentials | Yes | Generated by `docker-setup` |
| `LOGIN_USERNAME` | Initial user, used only on first start | Yes | `admin` |
| `LOGIN_PASSWORD_HASH` | Hash of the initial password (`docker-setup` generates it) | Yes | empty |
| `FINNHUB_API_KEY`, `EODHD_API_KEYS`, `ALPHA_VANTAGE_API_KEYS` | Market data keys; normally set in Ajustes › API instead | No | empty |
| `ETHERSCAN_API_KEY` | Etherscan v2 key to read Ethereum wallets (BNB only with a paid Etherscan plan); can also be saved from the wallets screen, a tracking's **Editar** window or **Ajustes › API** (a single key: saving another replaces it) | No | empty |
| `NODEREAL_API_KEY` | NodeReal key, a free-plan alternative to read BNB Smart Chain wallets; choose the BNB API in **Ajustes › API › Estado de las APIs**. Can also be saved in **Ajustes › API** (a single key: saving another replaces it) | No | empty |
| `TZ` | Container time zone (logs and backups) | No | `Europe/Madrid` |
| `PORT` | HTTP port; overrides `config.ini` | No | `5050` |
| `PUID` / `PGID` | User and group the container writes as (Linux) | No | Set by `docker-setup` |

## 📋 Usage guide 🕹️

1. Run `docker-setup` and choose how to create the account: **1** web (it prints the `/setup` address and a one-time code), **2** terminal, **3** quit.
2. Open `http://localhost:5050` and sign in.
3. Add your assets and operations. Without API keys, enter prices manually.
4. Optional, in **Ajustes** (Settings):
   - **API**: Finnhub, EODHD or Alpha Vantage keys for automatic quotes.
   - **Seguridad › HTTPS**: if you access it from other devices.
   - **Telegram**: alerts and commands (`/estado`, `/cartera`, `/backup`).
   - **Cuenta**: two-step verification with a Telegram code and a recovery phrase.
   - **Módulos**: which modules appear in the menu and which one opens at startup.

| Where | What you do there |
| --- | --- |
| Asset page › **Gráfico** | Price or return of your position, with your buys and sells marked |
| **Mi dinero › Cuentas / Movimientos / Cuenta remunerada** | Balance and history of each account, transfers and interest earned |
| **Cripto › Transacciones › ··· › Wallets enlazadas** | Import your wallets' movements from the blockchain (never paste private keys or seed phrases) |
| **Cripto › Seguimiento** | Group your own or third-party wallets, view their history, UTXOs and tokens, and get Telegram alerts |

Every screen is explained in detail in the [full usage guide](docs/guia-de-uso.md) (in Spanish).

```bash
docker logs -f PorfolioManager   # follow the logs
docker logs -f PorfolioManager-worker   # background tasks
docker compose down              # stop the stack
```
